## Summary

Package metadata is bumped to `0.4.2` so downstream hosts can consume the
envfile-aware shared Caddy reload fix from
[0074](0074-caddy-envfile-reload.md).

## Why

Static-site deploys that use relative `static_root` values depend on
`{$OPHELIA_STATIC_ROOT}` in shared Caddy snippets. This release makes the fix
available from a tagged Ophelia version.

## Changed Areas

- `pyproject.toml`: bumps package metadata to `0.4.2`.
- `README.md`: updates the visible version badge and version example.
- `docs/ROADMAP.md`: updates the active status line.
- `docs/changelog/INDEX.md`: records this release.

## Contract Impact

The package version is now `0.4.2`. Runtime behavior changes are limited to the
shared Caddy reload correction described in
[0074](0074-caddy-envfile-reload.md).

## Safety Impact

No runtime state is mutated by this release metadata change.
