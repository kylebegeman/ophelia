# Ophelia Documentation Archive

Status: historical reference

This archive keeps superseded plans, handoff notes, and build-agent prompts out
of the active documentation path while preserving the context behind previous
implementation phases.

Current planning lives in [Roadmap](../ROADMAP.md). Current entrypoints live in
[Documentation](../README.md) and [LLM Start Here](../llm/START_HERE.md).

## Contents

| Folder | Contents |
| --- | --- |
| [planning](planning/) | Long-form roadmaps, product findings, migration plans, and architecture drafts that guided the 0.3.0 work. |
| [handoffs](handoffs/) | Superseded operator handoff notes retained for history. |
| [prompts](prompts/) | Superseded build-agent prompts retained as implementation context. |

## Rules

- Do not start new implementation from archived plans.
- Do not add private deployment values, hostnames, credentials, or retained-app
  notes here.
- If an archived item becomes relevant again, promote the stable decision into
  an active doc and add a new change record.
