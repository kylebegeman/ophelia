## Summary

Prepare Ophelia 0.6.0 as the independent host-runtime release for Lumen
integration. It combines manifest v2 and the journaled Compose kernel,
`opheliad`, authenticated outbound fleet control, lifecycle-safe upgrades,
encrypted recovery, and continuous observations.

## Why

Lumen needs one pinned Ophelia build that can be installed, enrolled, operated,
observed, upgraded, backed up, and recovered through explicit versioned
contracts. These capabilities form a new minor release rather than a patch to
the 0.5 kernel foundation.

## Contract Impact

The package version becomes `0.6.0`. Remote protocol version 1 and manifest v2
remain pre-1.0 contracts and can evolve deliberately during the first Lumen
integration and disposable-host drills. Valid legacy manifests retain their
explicit compatibility lane.

## Safety Impact

This version bump does not enroll a host, publish a tag, deploy an app, or
authorize production mutation. All new remote mutations remain signed,
scoped, sequenced, journaled, and replayable. Backup and recovery retain their
own host-state and confirmation gates.

- strict public-surface audit

## Follow-Ups

- Perform disposable Linux enrollment, recovery, revocation, and upgrade drills.
