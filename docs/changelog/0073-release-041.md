## Summary

Package metadata is bumped to `0.4.1` so downstream apps can consume the Lumen
deploy ergonomics work from [0072](0072-lumen-deploy-ergonomics.md).

## Why

Lumen and static-site deployments on the OVH VPS need app-owned deploy metadata,
native shared Caddy reload, and internal verification schema normalization
available from a tagged Ophelia version.

## Changed Areas

- `pyproject.toml`: bumps package metadata to `0.4.1`.
- `README.md`: updates the visible version badge and version example.
- `docs/ROADMAP.md`, `docs/README.md`, `docs/llm/manifest.json`: update active
  documentation references from the older line to `0.4.x`.
- `docs/changelog/INDEX.md`: records this release.

## Contract Impact

The package version is now `0.4.1`. No new behavior beyond the contracts
recorded in [0072](0072-lumen-deploy-ergonomics.md).
